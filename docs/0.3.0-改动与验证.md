# Clibo 0.3.0 改动与验证

日期：2026-09-05。

## 已完成

1. 搜索/分类/分组/呼出周期绑定查询结果；查询未完成时禁止列表交互、回车回粘和仅复制，过期结果不能覆盖新结果。操作使用即时互斥标记，连续 Enter 不重复提交。
2. 合并粘贴统一保留队列；推进队列在同一粘贴互斥周期内完成。修改队列保存上一份顺序，5 分钟内可恢复，保护到期后回到正常保留规则。面板内 Ctrl+Q 进入排列粘贴。
3. 插入历史只借用已有记录计算淘汰计划；事务提交后增量更新内存。搜索字段在加载、插入和备注变更时生成；查询词只归一化一次，队列位置用 HashMap 查找。搜索不再清理数据库；清理历史不再同步 VACUUM。
4. 历史列表采用固定 84px 行步长的虚拟窗口。图片小图 320×240 以内，DB 加密缓存最多 128 张，前端最多 64 张/4 MiB 字符串预算、并发 2，取消尚未执行的过期预览。图片解码在历史锁外执行。复制、拖拽保留原图。
5. 文字处理提供去首尾空白、合并多余空行、大小写转换、JSON 格式化，预览后复制或粘贴；原文不变，桌面 JSON 格式化保留大整数精度。
6. 命名队列支持保存当前顺序、载入、改名和移除。最多 30 份，加密持久化，引用原记录并保护自动淘汰；手动删除历史仍生效。快照只传命名队列名称/数量，不在每次搜索传输所有保存的引用。
7. 数据库 v1–v3 → v4 升级前，SQLite VACUUM INTO 生成一致性加密备份，备份失败停止升级。新增缩略图表随原记录删除级联清理。

## 验证结果

- Rust：20 项测试通过，覆盖现有图片格式、分组、去重、加密、事务回滚，以及新增文字转换、命名队列重启/恢复/保留、缩略图加密和级联删除、升级恢复副本、已有正文分配不被复制。
- 前端：9 项测试通过。包含搜索等待时 Enter/Shift+Enter 禁止提交、乱序响应、输入法组词保护、2,000 条只挂载少于 20 行并跨窗口键盘导航、重复 Enter 互斥、缩略图请求并发/取消/缓存预算。
- TypeScript / Vite 构建、Clippy `-D warnings` 通过。
- 浏览器合成数据：验证命名队列保存、清空和恢复、文字处理预览、无效 JSON 禁用复制/粘贴；680×560 队列布局和拖动从第 1 到第 2 条通过；560×420 的处理面板可见。

## 边界与后续

- 未用用户真实剪贴板做压力测试；尚未完成 8 小时常驻、冷/热呼出 P95、进程树内存及跨应用回粘矩阵。结构优化和单元测试不能代替这些实机指标。
- Windows 只能报告是否发出粘贴按键，不能证明目标应用收到内容。队列保留/恢复用于重试。
- SQLite 清理后复用空闲页，不保证立即缩小文件；缩略图、升级备份不计入原有内容逻辑容量上限。升级备份需要额外磁盘空间。
- OCR、增强搜索、定时暂停和完整备份管理界面仍属于后续功能。本次完成评审中优先排定的修复、性能优化、文字处理和命名队列。
