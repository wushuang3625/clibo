# Clibo 0.3.1 体验项修复与验证

日期：2026-09-05。本次完成原评审第 2 部分列出的全部 6 项体验修复，包含 0.3.0 已完成的相关修复。

| 体验项 | 最终行为 |
|---|---|
| 搜索期间误贴旧选择 | 查询、筛选、分组和呼出周期绑定结果；待查询时禁止旧列表操作和 Enter/Shift+Enter，丢弃乱序返回。同步操作锁拦截重复 Enter。 |
| 合并队列行为不一致、不可恢复 | 桌面与演示统一合并后保留队列；清空、推进或改序后提供 5 分钟恢复上一份非空队列。使用说明同步修正。 |
| 继续队列步骤多、队首不清楚 | 默认 Ctrl+Alt+Q 直接呼出排列并选中队首，保留已有普通呼出设置；面板内 Ctrl+Q。顶部摘要和列表标记指明下一条，摘要点击清除筛选并定位队首。 |
| 队列控制区占用空间、列表过小 | 压缩工具栏，预览可折叠并恢复；折叠后底部仍有粘贴/仅复制。虚拟列表保留键盘导航和拖动排序。 |
| 图片难以区分 | 列表缩略图、原始宽高、复制时间与完整时间悬浮提示；预览尺寸来自原图，支持按需查看原图。复制和拖拽保持原图。 |
| 失败显示成功、缺少恢复入口 | 成功勾选、手动粘贴警示、失败警示分开；失败/手动提示持续保留，提供重试和仅复制。原生回粘失败重新显示面板；文字处理失败保留预览。刷新失败不会邀请再次粘贴。 |

快捷键注册错误独立显示，避免被采集状态覆盖；设置保存失败回滚新注册快捷键。旧设置缺少队列快捷键时补默认值，保留用户原呼出键。

图片尺寸使用独立元数据表，随历史删除级联清理；不重复解码原图。数据库仍为结构版本 4，本次增加兼容的表，不改变已有加密内容。0.3.0 的首次 v4 升级备份、文字处理与命名队列继续保留。

## 自动验证

- Rust：21 项测试通过，包含旧设置兼容、原图尺寸、缩略图加密/级联删除、队列恢复/持久化/保留、数据库升级备份、文字处理及原有存储与图片校验。
- 前端：16 项测试通过，包含待搜索保护、乱序响应、输入法、2,000 条虚拟列表、操作互斥、独立队列呼出事件、预览折叠复制、失败重试、手动复制恢复、刷新失败不重复粘贴、文字处理失败保留预览及缩略图请求限制。
- TypeScript / Vite、Clippy `-D warnings` 和 Windows x64 Release 构建通过。
- 浏览器合成数据：680×560 默认队列布局、560×420 折叠预览布局、合并保留、逐条推进和恢复队列通过；折叠后粘贴/复制仍可见。

## 验证边界

浏览器使用合成示例数据验证界面，原生设置兼容与数据操作使用独立测试数据库。没有对用户真实剪贴板做测试修改。

全局快捷键的系统注册冲突、窗口焦点恢复及跨应用真实回粘仍需在目标应用中验收；不能将浏览器交互或单元测试视为此类实机验收通过。Windows 只报告粘贴按键是否发出，无法确认目标接收。长时间常驻和性能指标仍按原计划待测。
