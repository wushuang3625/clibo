# Windows 剪贴板工具：任务规划

> 规划日期：2026-09-04。项目暂称 Clibo，名称仅沿用工作目录，尚未核验商标或域名。用户已确认采用 Rust 方案开始实施；当前进度及验证结果见 [实施进度](实施进度.md)，下文保留完整产品验收路线。

## 1. 产品决策与假设

建议定位：给中文办公及开发用户使用的本地剪贴板工具，让用户用键盘迅速找到并复用复制过的文字和图片。

首发按 Windows 11 x64、单人全职、每天约 6 小时有效开发估算。原始估算基于已有 C# 基础；现已按用户偏好选择 Rust，学习与 Windows 集成成本需根据实测重新估算。面向个人使用者进行小范围验证，商业模式暂不锁定。Windows 10、ARM64、团队管理和跨设备同步分别立项评估。

核心路径：复制内容 → 自动记录 → 自定义热键呼出 → 输入关键词 → 方向键选择 → Enter 粘贴 → 返回原应用。建议候选热键 Ctrl+Alt+V，安装后检查冲突并允许改键，不接管系统 Win+V。

首版成功标准不是功能数，而是目标用户能持续用它替代“回原应用重新找”。必须同时记录失败原因：没捕获、没搜到、目标失焦、格式不对、拒绝记录规则误判。

## 2. 范围与优先级

| 优先级 | 能力 | 明确边界 |
|---|---|---|
| P0 | 文本、URL、代码片段历史 | URL 与代码先按文本处理；保留空白与换行；不执行内容 |
| P0 | 图片历史与缩略预览 | 支持明确列入兼容矩阵的位图/PNG来源；限制体积与像素；不做图片编辑 |
| P0 | 搜索、类型筛选、收藏 | 支持中文子串与英文不区分大小写；拼音、语义搜索不在首版 |
| P0 | 热键、托盘、键盘导航、自动粘贴 | 失败可退回“已复制，请手动粘贴”；不承诺所有程序自动粘贴成功 |
| P0 | 去重、容量与保留期、删除 | 暂定 2,000 条、30 天、磁盘 1 GB；收藏不受年龄淘汰，但受总容量约束并提示 |
| P0 | 暂停记录、排除应用、敏感标记、静态内容加密 | 不保证识别所有密码；不自动上传；日志不含正文/图片/查询词 |
| P0 | 安装、卸载、恢复、诊断 | 本地内测包；卸载保留或删除历史由用户选择；升级先验证迁移 |
| P1 | 富文本、文件引用、OCR、常用片段分组 | 文件引用不等于文件备份；OCR优先本地且需单独测体积/语言包 |
| P1 | 批量粘贴、拼音搜索、导入导出 | 对高频场景验证后逐项做；导出需明确格式、加密和敏感数据提示 |
| P2 | 同步、AI转换、脚本、团队功能 | 有独立需求证据才立项；账号、加密、冲突和持续成本另估 |

容量参数是待压测的起始值。文本单条暂定 1 MiB，累计可搜索文本 16 MiB；图片单条 10 MiB、解码后不超过 25 MP。超限时明确跳过，不能截断后伪装完整记录。图片内容不参与文字搜索；图片按类型和时间查找，来源可用时辅助筛选。

## 3. 推荐技术路线

已确定采用 Rust + Tauri 2 + React / TypeScript，存储为 SQLite。托盘与热键、剪贴板监听、窗口焦点和粘贴通过 Windows API 适配。Rust 负责系统能力、数据和规则，前端负责面板与设置。

Windows 上 Tauri 使用 WebView2，必须连同进程总内存、首次呼出和窗口焦点一起测；不能仅凭安装包体积判断轻量。初版仍只承诺 Windows 范围，不由技术框架推导跨平台已经可用。

数据流建议：平台监听 → 读取快照 → 排除规则 → 内容标准化与去重 → 加密持久化 → 内存搜索 → 面板 → 写回剪贴板与目标窗口粘贴。

默认加密方案先验证 Windows DPAPI CurrentUser 保护正文、图片、预览和敏感来源字段；SQLite 只存必要的 ID、时间、类型、字节数等非正文元数据。搜索索引仅在进程内存中生成并限定总体量，避免加密正文、明文索引的矛盾。退出清理引用，但不承诺系统分页文件或崩溃转储绝无残留。DPAPI 不防同一登录用户下的恶意程序，跨账户迁移不能靠直接复制数据库。

2,000 条规模先用取消过期查询的内存子串匹配；中文一至两个字必须可查。需要扩到 10,000 条以上时再验证加密数据库及 FTS5/trigram；普通 unicode61 不是中文分词器，trigram 对不足三个字符的查询需要另外处理。这是扩容技术债，不应挡住第一轮需求验证。

基础合计 30 人日，加 6 人日风险缓冲，共约 36 人日。内测等待可与修复重叠，按全职约 7-8 周安排；兼职每周10小时按216有效小时粗算约22周。T02若技术栈不熟悉或关键兼容性失败，应重新估算，不用缓冲掩盖范围变化。

隐私规则不能等到 T11 才考虑：T05预留并接入过滤接口，T06完成加密，T11负责完整覆盖和验证。T02只使用合成数据；T11完成前不分发给真实用户日常采集。

## 6. 发布门槛与验收样本

以下均为目标，尚未实测。基准机建议 Windows 11、4核以上CPU、16 GB内存、SSD；固定系统版本、显示缩放、测试集和构建模式后比较。

- 日常路径：2,000条、累计16 MiB文本条件下，热键至面板可输入的P95不高于150 ms，输入结束至结果可用P95不高于100 ms；至少100次测量。冷启动单独记录，不能拿预热结果替代。
- 资源：静置10分钟的平均CPU低于0.5%，稳定工作集目标低于150 MB；图片缓存压力后应回落。结果受设备影响，未达标先归因并收敛缓存。
- 采集：合成脚本每秒复制5次、共1,000次，目标捕获率至少99%；明确不承诺无限速、延迟渲染或来源在读取前覆盖的数据不丢失。
- 回粘：定义200次组合测试，目标文本至少99%正确回粘，覆盖记事本、浏览器输入框、VS Code、Word；图片覆盖截图工具到聊天输入框/Word。管理员窗口、远程桌面、虚拟文件和未支持格式单列，不混入成功率。
- 隐私：排除应用、三类系统标记、暂停与清理的每个既定用例100%通过；检查库、WAL、图片目录、日志与导出诊断，不仅看UI里是否消失。
- 故障：断电模拟/强制结束后可重启；数据库不可写或磁盘满时不死循环；升级迁移失败保留可恢复文件；应用自身写回不产生采集风暴。
- 交互：100%、150%、200%缩放及两屏混合缩放；中文IME组词时Enter不提前粘贴；屏幕阅读器标签、可见焦点与Esc返回可用。

目标窗口内容是否真的被应用接收，不是通用输入注入返回值能够证明的；兼容测试由目标文本/图片核验，产品内只记录“尝试回粘”，不把它当作真实成功率。

删除承诺限定为本应用管理的数据，不保证删除已进入其他应用、系统剪贴板历史、备份、同步服务或磁盘历史快照的副本。普通删除也不宣称取证级不可恢复。检测到来源不愿进入历史的系统标记时先拒绝记录；禁止云同步标记本身不等同于禁止本地历史。

## 7. 内测与业务判断

招募10名自愿试用者，开发/办公各约一半，先用合成或非敏感内容走查。邀请前问清当前使用Win+V、Ditto、CopyQ还是完全不用历史工具，分别记录。

建议门槛：至少7/10完成首次“复制→找到→粘贴”，至少5/10在第7天仍主动使用，并且至少5人能讲出一项相较原工具的具体收益。这些只是小样本继续投入阈值，不能推断市场占有率、总体留存率或付费转化。

默认无遥测；由用户在本地查看记录次数、主动召回次数和失败分类，选择是否分享不含正文的统计。回访讨论真实任务完成时间，不上传复制内容、来源窗口标题、路径或搜索词。

若访谈说明“系统已经够用”，缩小到中文重度用户或作为个人工具结束。若必须同步才愿使用，先验证同步原型与付费意愿并重估成本，不直接把同步塞入当前版本。若主要诉求是团队话术，另走片段模板工具定位。

## 8. 风险、降级与后续任务

| 风险 | 提前验证 | 降级或处理 |
|---|---|---|
| 焦点与权限导致误粘贴 | T02、T08检查目标窗口与完整性级别 | 无法确认目标时只复制，提示手动粘贴；不默认提权 |
| 来源识别并不可靠 | 对剪贴板所有者及进程做最佳努力识别 | 未知来源明确展示；应用排除不宣称能精准到浏览器站点 |
| 图片体积引发卡顿 | T10限制编码大小、像素、队列和缓存 | 超限跳过并说明；不无限生成缩略图 |
| 明文索引破坏加密承诺 | T02/T06检查设计与实际文件 | 首版仅内存搜索；扩容才评估整库加密和全文索引 |
| 加密数据不可迁移 | T02验证账户绑定、备份恢复 | 首版说明同账户恢复范围；P1另做口令保护的导出 |
| 需求扩张拖延上线 | 每周冻结一次P0 | P1进入后续清单，有真实频次证据才提级 |

P1候选任务：R01富文本格式往返（2-4日）；R02文件引用与失效提示（2-3日）；R03本地OCR及语言包（3-5日）；R04片段分组、编辑与快捷调用（2-4日）；R05批量粘贴和顺序队列（2-4日）；R06加密导入导出（3-5日）；R07拼音及大规模搜索（3-5日）。均依赖M6需求复审，估算待验证，不能自动相加视为下一版承诺。

## 9. 规划依据

技术事实于2026-09-04核验；实现方案和指标属于本项目建议。

- [WPF 概述](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/)：Windows桌面框架。
- [.NET 支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy)：.NET 10为LTS，支持结束日期为2028-11-14。
- [Tauri WebView 说明](https://v2.tauri.app/reference/webview-versions/)：Windows使用WebView2。
- [剪贴板监听](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-addclipboardformatlistener)：基于通知的监听入口。
- [SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)：受完整性级别限制。
- [剪贴板格式与历史控制](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-formats)：多格式及排除标记。
- [SQLite FTS5](https://www.sqlite.org/fts5.html)：分词与trigram的适用范围。
- [DPAPI CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)：账户相关的数据保护与恢复边界。
