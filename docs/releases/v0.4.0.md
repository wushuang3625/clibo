# Clibo 0.4.0

Clibo 0.4.0 是 Rust 原生桌面版本预览版。

## 主要内容

- Windows x64 原生便携版，不依赖 Node、WebView 或其他运行时。
- 支持文字、链接、PNG / DIB 图片历史，以及搜索、收藏、备注和分组。
- 支持全局快捷键、托盘、固定面板、失焦隐藏和单实例。
- 支持排列粘贴、文字处理和临时计算器。
- Windows 使用 DPAPI 保护剪贴板正文、来源、图片和设置。

## 下载与运行

下载 `Clibo-0.4.0-windows-x64.zip`，解压后直接运行 `Clibo.exe`。

## 数据位置

Windows 默认将数据保存在：

```text
%LOCALAPPDATA%\local.clibo.native\history.db
```

旧版 Tauri 程序使用的 `local.clibo.desktop` 数据不会自动迁移。

## 已知限制

- 当前提供的是便携版，没有安装器、自动更新和代码签名。
- macOS 尚未完成 `.app` 打包、签名和实机验收，因此本次 Release 仅提供 Windows x64 构建。
- 跨应用回粘、输入法、多屏 DPI 和权限差异仍建议在目标环境中逐项验收。
