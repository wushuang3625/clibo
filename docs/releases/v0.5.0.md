# Clibo 0.5.0

Clibo 0.5.0 adds a timestamp workspace and Windows login startup to the native desktop app.

## What's new

- Timestamp conversion between seconds / milliseconds and date-time values.
- Fixed UTC offsets for UTC and Beijing time, plus batch conversion.
- JSON workspace, calculator, clipboard history, and image preview improvements from the previous development cycle.
- Windows login startup from Preferences, using the current user's Run key without administrator privileges.
- Manual history backup and restore with a safety backup before restoration.

## Download

Download `Clibo-0.5.0-windows-x64.zip`, extract it, and run `Clibo.exe`.

The portable package does not require Node, WebView, or an installer.

## Data location

Windows stores local data in:

```text
%LOCALAPPDATA%\local.clibo.native\history.db
```

Clipboard content is processed locally and is not uploaded.

## Known limitations

- This release provides a Windows x64 portable package only.
- There is no installer, automatic updater, or code signing yet.
- macOS native code is included, but `.app` packaging, signing, and a downloadable build are not complete.
