# Clibo 0.6.0

Clibo 0.6.0 introduces the native launcher, packaged Windows Store app discovery, command mode filters, in-panel shortcuts, and refined UI styling.

## What's new

- **Native launcher**: Press `Alt + S` to summon a compact launcher to search apps, local files, browser bookmarks, Windows settings, instant calculations, and web search.
- **Windows Store apps**: Full scanning and activation for packaged Windows Store applications (`shell:AppsFolder`), complete with native 32x32 icon extraction.
- **Tool command mode**: Type `>` or `》` in the search box to list Clibo internal tools directly.
- **In-panel shortcuts**: Configure dedicated in-panel shortcuts for the JSON workspace and timestamp converter under Preferences.
- **UI & design refinements**: Transparent panel styling, adjusted button sizes, and theme polish.
- **Continuous integration**: Extended native test suites across Windows and macOS runners.

## Download

Download `Clibo-0.6.0-windows-x64.zip`, extract it, and run `Clibo.exe`.

The portable package does not require Node, WebView, or an installer.

## Data location

Windows stores local data in:

```text
%LOCALAPPDATA%\local.clibo.native\history.db
```

Clipboard content is processed locally and is not uploaded.

## Known limitations

- This release provides a Windows x64 portable package only.
- There is no installer, automatic updater, or code signing yet.
- macOS native code is included, but `.app` packaging, signing, and a downloadable build are not complete.
