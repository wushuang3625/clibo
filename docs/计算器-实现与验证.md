# 计算器实现与验证

日期：2026-09-08。

## 已实现

原生面板新增独立计算模式，搜索首字符 `=` / `＝` 触发，退出恢复原有固定状态。支持十进制运算、括号、一元符号、百分数、科学计数法输入、全角归一化，错误/未完成状态不提供旧结果复制。独立模块不执行脚本。

Enter 确认、运算符续算、数字或粘贴开始新算式；Shift+Enter 复制完整结果。最近 50 条只驻留内存，支持回填、复制、移除、清空及 5 秒撤销。支持草稿恢复、模式收起再呼出、设置与主题切换；排列快捷键退出计算。

## 验证

- 36 项自动测试通过，包括 4 项计算器测试（多组算术、无效输入、边界、历史与续算案例）。
- 最终代码静态检查通过（Clippy，警告视为错误）；深浅主题原生隔离截图和 620×440 最小窗口的除零错误状态已检查。
- Release 构建完成，已通过项目导出脚本生成 `output/native/Clibo.exe`、使用说明和 SHA256，导出脚本校验源程序与输出程序哈希一致。
- 原生截图由程序自身输出，仅使用独立演示数据，采集保持暂停。
- 桌面自动化调用返回 `Computer Use was not approved to use clibo-native`，因此不宣称已完成真实鼠标/键盘及跨应用交互验收。中文输入法、按键焦点、跨窗口失焦保持及复制还需人工试用确认。

## 与设计规格的实现差异

- 数值使用 rust_decimal 的实际表示范围：约 28–29 位有效数字，小数最多 28 位，而非任意指数的 28 位有效数字。极小值超范围会报错。
- 错误以具体文案与字符位置提示，尚未绘制输入框内的字符下划线。
- 复制后的状态提示为 3 秒；复制操作将焦点放回算式末尾。
- 大数保留可横向查看的十进制表示，没有强制切换科学计数法展示。

详细交互规格参见《计算器交互设计-v1.md》。
