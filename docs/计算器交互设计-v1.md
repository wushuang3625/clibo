# Clibo 计算器交互设计 v1

日期：2026-09-08。状态：第一版已接入原生应用，具体完成项、差异及测试边界见《计算器-实现与验证.md》。本文件保留目标交互规格。

## 1. 目标与依据

在剪贴板面板内完成随手计算、连续计算和复制结果。用户在搜索框开头输入 `=` 即进入计算模式，窗口临时固定，允许切换到其他应用查看数字。

沿用项目现有原生界面、深浅主题、品牌细线、字体及间距。依据 `native/src/ui.rs`：默认窗口 780×580、最小 620×440；面板已有固定、失焦隐藏及搜索框。以下均为新增功能的设计决定，不代表现有功能。

设计假设：优先键盘使用；计算在本地完成；第一版面向日常算术；保持一个窗口，不改变窗口大小或位置。

## 2. 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ CLIBO  计算器                    计算中·已固定   外观  设置 收起 │
│ [ = ]  128 * 3 + 56                          清空  返回剪贴板 │
├──────────────────────────────────────────────────────────────┤
│ 实时结果                                                     │
│ 440                                                          │
│                                      [复制算式] [复制结果]    │
├──────────────────────────────────────────────────────────────┤
│ 最近计算                                  清空记录           │
│ 1200 / 8                                150         复制     │
│ 99 * 0.85                               84.15       复制     │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ Enter 确认计算 · Shift+Enter 复制结果 · Esc 返回               │
└──────────────────────────────────────────────────────────────┘
```

示意中的历史是说明数据，首次使用不预填记录。

- 顶栏保留品牌、外观、设置、收起；计算器名称替换“本地剪贴板”。采集开关留在剪贴板模式，计算期间采集状态不变。
- 搜索区域原位变为表达式输入框。`=` 为固定模式标识，不属于可编辑算式。右侧有“清空”和“返回剪贴板”，窄窗口允许清空收为带提示的图标。
- 结果区域约 150 高；结果字号 36–44，等宽或表格数字。标签区分“实时结果”“已确认”“需要补全”“无法计算”。
- 最近计算占据剩余空间并独立滚动；底部快捷键栏固定。最小窗口下不遮挡输入、结果或按钮。
- 结果按钮始终占位，无有效结果时禁用。历史行右对齐结果，表达式过长省略，悬停显示全文。
- 长结果减小字号至 24 后允许横向滚动；不截断用于复制的值。大数可以科学计数法展示。
- 深浅主题直接使用现有主题色。重点只放在输入焦点和结果，不新增装饰图片。

## 3. 进入计算模式

1. 搜索内容的第一个字符是半角 `=` 或全角 `＝` 时触发。输入法组合期间不触发，提交后判断。
2. 支持一次粘贴 `=128*3`；转换后输入框为 `128*3`，光标停在末尾。粘贴多行不自动求值，提示“每次输入一个算式”。
3. 普通搜索中间的等号不触发，如 `a=1` 仍搜索剪贴板。
4. 进入时保存筛选、分组、选中项及列表滚动位置；退出时恢复，搜索框清空并获得焦点。
5. 空白计算页提示“输入算式，结果会实时显示”，提供可点击示例 `128*3+56`、`(1200-200)/8`。点击仅填入，不生成历史。
6. 普通搜索框提示改为“搜索内容、来源、分组或备注，输入 = 计算”。
7. 需要搜索以等号开头的文本时，输入 `\=SUM`，按字面搜索 `=SUM`。计算空白页提供“按文本搜索 =”入口：返回搜索页并填入转义形式。连续第二个等号不再次切换模式，在计算框中提示不支持比较运算。

## 4. 固定、收起与退出

计算模式强制临时固定：点击其他窗口不会收起。顶栏固定按钮改为“计算中·已固定”的状态提示，提示内容为“返回剪贴板后恢复原来的固定设置”；计算期间不允许切掉临时固定，避免行为不确定。

- `Esc`：无弹层、无输入法组合时，立即返回剪贴板；保留计算草稿到当前进程内。再次 Esc 沿用剪贴板规则。
- “返回剪贴板”：与 Esc 一致，恢复进入前固定状态。
- 算式为空且光标在起点，按 Backspace：返回剪贴板。
- “收起”或系统关闭窗口：隐藏面板，保留当前计算模式、草稿和临时固定状态；下次普通呼出恢复并聚焦算式。收起不会退出程序。
- 普通呼出快捷键：遵循现有呼出行为；显示计算模式并聚焦输入框，不把焦点回到剪贴板列表。
- 排列粘贴快捷键：明确进入原有排列流程，退出计算并恢复原固定状态，草稿保留。
- 退出计算后再次仅输入 `=`：显示空算式；如有未完成草稿，显示“恢复上次算式”轻量入口。输入 `=表达式` 则优先新表达式。
- 设置弹层打开时 Esc 先关设置；输入法组合时 Esc 先交给输入法，不退出计算。
- 重启应用回到剪贴板模式，不恢复临时固定与草稿。

## 5. 实时计算与确认

有效表达式实时显示预览，只有按 Enter 才确认并写入最近计算。确认后保留原表达式，标签变为“已确认”，输入框焦点保留；连续按 Enter 不重复添加、不重复执行上次运算。

确认后的下一次输入：

| 输入 | 行为 |
|---|---|
| `+ - * /` | 以上次计算内部结果继续，例：440 后输入 `*2` 得到 880 |
| 数字、小数点、左括号、粘贴 | 开始新算式，替换上一条 |
| 左右方向、Home/End、点击算式、Backspace/Delete | 进入原算式编辑，后续按普通文本框行为 |
| Ctrl+A 后输入 | 替换选中内容，不触发续算 |
| Esc | 返回剪贴板 |

确认后如果需要输入负数作为新算式，先清空再输入 `-5`，或直接粘贴 `-5`。底部确认态文案改为“输入运算符继续计算，输入数字开始新计算”。

“清空”只清空当前算式，保留历史与模式，恢复输入焦点。用户主动选中或编辑过算式后，不再套用“确认后的首键”规则。

## 6. 复制

- Shift+Enter 或“复制结果”：复制当前有效结果的纯数值，不含千位分隔符、标签、约等号或换行。复制不自动确认或产生计算历史。
- “复制算式”：复制单行 `128 * 3 + 56 = 440`。近似结果使用 `≈`。
- 历史行“复制”：复制该条结果，不改变当前输入。
- 成功显示“已复制”约 1.5 秒，不抢输入焦点；失败显示“复制失败，请重试”，保留算式与结果。
- Ctrl+C 遵循文本选择：输入框中复制选中表达式，结果区域有选择时复制选中文字。没有选择时不冒充“复制结果”。
- 第一版不提供自动回粘；用户可切回目标应用粘贴。原剪贴板模式 Enter 粘贴不变，计算模式 Enter 不触发该处理器。
- 只有主动复制才写剪贴板，实时计算不写。复制出的结果是否进入剪贴板历史，遵循原有采集开启状态、过滤和去重规则，不另行强制插入。

## 7. 运算范围与数值规范

第一版支持十进制整数、小数、前置正负号、加减乘除、括号和后缀百分号。接受 `× ÷ −`、全角数字及全角括号并归一化；空格可忽略。暂不支持函数、幂、单位、汇率、进制、变量、比较运算或程序执行。

- 优先级：括号、百分号、一元符号、乘除、加减；同级二元运算从左到右。
- `%` 始终代表除以 100：`200+10% = 200.1`；涨价 10% 写作 `200*(1+10%) = 220`。首次输入 % 时展示这条说明。
- 不支持隐式乘法：`2(3+4)` 提示“括号前请加乘号”；不支持 `1,000`，提示“请移除数字中的逗号”。
- 不静默补括号、不忽略不支持字符、不把异常算式部分求值。
- 建议使用十进制数值语义，精度目标 28 位有效数字；超过精度的运算标为近似。标准显示最多 12 位有效数字，舍入采用四舍五入；舍入发生时显示 `≈`，可展开“更多位数”。
- “复制结果”复制内部结果的规范字符串，最高 28 位有效数字；按钮提示明确“复制完整结果”。续算也使用内部值，不用缩短后的显示值。近似值展开后仍说明“近似结果”。
- 去掉无意义末尾零，`-0` 规范为 `0`。科学计数法展示/复制的结果必须能粘回计算框求值（支持数值中的 e/E 指数，但不支持独立常量 e）。
- 长度限制 4096 字符、括号嵌套上限 64；超限明确提示，不截断后继续求值。结果超出数值范围提示“结果超出支持范围”。

## 8. 最近计算

第一版仅保存在当前进程内，最多 50 条，最新在上。重启清空；退出模式或收起窗口不清空。只记录用户确认的有效计算。

- 连续相同表达式、相同结果确认只保留一条；隔着其他计算再次确认可生成新条目。
- 点击表达式回填，进入编辑态并聚焦输入，不自动确认。结果文本允许选择；复制按钮独立响应，不触发行回填。
- 单条支持“移除”；“清空记录”即时执行，并提供 5 秒“撤销”，无需确认弹窗。撤销恢复被清除记录并与期间新增记录合并，仍限制为 50 条。
- 空状态：“确认后的计算会出现在这里”，不显示伪造数据。
- 键盘 Tab 可到达历史行与操作按钮；Enter 在历史行回填，在按钮执行按钮动作。全局“确认计算”只在算式框获得焦点时响应。

## 9. 状态与反馈

| 状态 | 结果区域 | 操作 |
|---|---|---|
| 空 | 输入算式，结果会实时显示 | 复制禁用 |
| 未完成，如 `12*` | 继续输入数字 | 复制禁用，Enter 不生成历史 |
| 括号未闭合 | 还差一个右括号 | 复制禁用 |
| 有效 | 实时结果及数值 | 可确认、复制 |
| 已确认 | 已确认及数值 | 可续算、复制 |
| 除零 | 不能除以 0 | 复制禁用 |
| 非法字符 | 不支持“字符”，请检查算式 | 标记对应位置，保留输入 |
| 超范围 | 结果超出支持范围 | 复制禁用 |
| 复制失败 | 保留结果，显示重试提示 | 可重试 |

无效输入后立即移除上一条结果的可复制状态，避免用户复制到旧值。未完成使用弱提示；确定错误使用错误色与文字，不只靠颜色区分。

## 10. 焦点、尺寸与无障碍

进入、清空、回填后聚焦表达式。复制后保持原焦点；设置关闭后恢复表达式焦点。键盘焦点有可见描边，图标有文字提示。Tab 顺序按视觉阅读顺序，结果更新不主动搬动焦点，也不每个字符都播报；确认与复制后提供状态通知。

输入框支持常规选择、撤销与重做；原始字符串和光标编辑行为优先。不得让历史快捷键抢占输入框上下左右或输入法按键。不同缩放和最小窗口下，按钮可紧凑排列，历史区域缩小，主要操作保持可见。

## 11. 验收场景

1. 未固定剪贴板输入 `=`，计算固定；点击其他应用保持显示；Esc 返回后恢复未固定。
2. 原本已固定时进入再退出，仍固定。收起再呼出保留正在计算的内容。
3. 粘贴 `=128*3+56` 显示 440；Enter 只新增一条；再 Enter 不新增。
4. 上例确认后输入 `*2` 得到 880；输入数字开始新算式；点击原算式可以编辑。
5. 输入 `0.1+0.2` 显示 0.3；`1/3` 标近似；续算使用内部精度。
6. `200+10%` 为 200.1，`200*(1+10%)` 为 220；百分数说明可见。
7. `1/0`、`2(`、非法字符等不会保留旧结果供复制，也不写历史。
8. Shift+Enter 复制纯数值且不回粘；剪贴板模式 Enter 仍保持现有粘贴行为。
9. `a=1` 仍搜索；`\=SUM` 搜索字面文本；中文输入法组合不会误退出或确认。
10. 历史回填、单条移除、清空撤销均可操作，退出计算保留历史，重启清空。
11. 最小尺寸和深浅主题下输入、结果与按钮不重叠；长结果可完整查看和复制。
12. 设置中的 Esc 只关闭设置；排列快捷键可正常进入排列流程，不被计算模式拦截。

## 12. 实施边界

新增独立计算模式状态和计算模块，原有搜索查询不承担算式求值。固定状态使用“用户固定或计算临时固定”组合判定，退出自动移除临时条件。原生代码是最终界面载体，本文件为可实施的交互规格。

后续可扩展可折叠数字键盘、持久化计算历史、科学函数；第一版不展示这些功能的空入口。
